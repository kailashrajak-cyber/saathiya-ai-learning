# Saathiya AI Companion

Build a professional flagship AI application called Saathiya AI.

Saathiya AI is an India-focused AI companion for learning, general health information, wellbeing, and cyber-safety.

IMPORTANT:

Do NOT make it look like a generic ChatGPT clone.

Create a distinctive premium product identity.

Make it fully responsive and mobile-first for Android phones.

Do not use fake testimonials, fake users, fake statistics, fake certificates, fake achievements or fake partnerships.

Do not expose API keys in frontend code.

Keep the architecture modular and ready for secure backend/API integration.

CORE SECTIONS:

HOME Create a premium hero section: "Saathiya AI" "AI that helps you learn, understand and stay safer."

Add buttons: "Start Chatting" "Explore AI Workspace"

Show feature cards: AI Chat, Student AI, Health Information, Cyber Safety, Document Intelligence.

AI CHAT Create a modern AI chat interface with:

Hindi/English language selector

message bubbles

typing/loading state

text input

attachment button

voice input UI

suggested prompts

new conversation

chat history

empty and error states

STUDENT AI Create tools for:

Explain a topic

Summarize notes

Generate quiz

Create study plan

Ask questions from documents

AI WORKSPACE Create the workflow: "Ask → Upload → Analyze → Explain → Save"

Include:

document upload interface

analysis/loading state

results panel

saved outputs

clear empty states

HEALTH INFORMATION Create a safe general health-information interface. Do not claim to diagnose diseases or replace healthcare professionals. Include educational health categories and a clear safety notice for serious concerns.

CYBER SAFETY Create defensive educational tools for:

Phishing awareness

Suspicious-message explanation

Password safety

Account security checklist

Cyber-safety learning

Keep all cybersecurity functionality educational and defensive.

DOCUMENT INTELLIGENCE Create a polished document-analysis interface supporting PDF/document workflows. Show summary, important points, questions and structured results.

DESIGN: Use a premium dark AI/cybersecurity visual identity:

deep indigo background

subtle teal glow

warm marigold accents

elegant glassmorphism

clean typography

smooth but subtle animations

excellent contrast

modern cards

professional spacing

Create a unique "Saathiya" visual identity. Do not copy ChatGPT, Gemini or another product.

MOBILE UX:

Mobile-first layout

comfortable touch targets

compact navigation

responsive cards

responsive chat interface

no horizontal scrolling

TECHNICAL QUALITY:

reusable components

clean architecture

proper loading/error/empty states

accessible controls

no unnecessary dependencies

secure environment-variable approach for secrets

modular AI/API service layer

clear code structure

preserve useful existing functionality if any exists

For now, focus on building the complete high-quality UI/UX foundation and application structure. Use clearly labelled demo data where real APIs are not connected yet.

Do not add unnecessary features outside this scope.
